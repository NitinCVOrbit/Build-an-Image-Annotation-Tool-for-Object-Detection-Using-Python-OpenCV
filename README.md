# Image Annotation Tool using Python & OpenCV

A simple and interactive **image annotation tool built with Python and OpenCV** that allows users to draw bounding boxes on images using the mouse and save annotations for **object detection datasets**.

This project is useful for creating custom datasets for **YOLO, Faster R-CNN, SSD**, and other computer vision models.

---

## 🚀 Features
- Draw bounding boxes using mouse drag
- Live rectangle preview while drawing
- Annotate multiple objects per image
- Undo last bounding box
- Save annotations to a text file
- Clean and beginner-friendly code

---

## ⌨️ Keyboard Controls

| Key | Action |
|----|------|
| `s` | Save bounding boxes |
| `z` | Undo last box |
| `q` | Quit application |

---

## 📝 Label Format
Each annotation is saved in the following format: class_id x1 y1 x2 y2
